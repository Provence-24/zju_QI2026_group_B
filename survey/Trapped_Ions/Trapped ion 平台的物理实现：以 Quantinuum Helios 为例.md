
# Helios 离子阱量子计算机：物理实现与性能基准

## 一、概览

Helios 是 Quantinuum 公司推出的第三代离子阱量子处理器，基于量子电荷耦合器件（QCCD）架构，集成了 98 个可操作的量子比特。与上一代 H1 和 H2 系统相比，Helios 在离子种类、陷阱几何结构以及经典控制软件上均做出了重大革新。具体而言，它首次在商业级离子阱计算机中使用 $^{137}\mathrm{Ba}^+$ 作为量子比特离子，并采用了一个带有四向“X”型交叉结的环形离子存储结构，从而在保持较低电控复杂度的前提下实现了全连接（all‑to‑all）的量子操作。此外，Helios 配备了一套全新的实时编译软件栈（Helios Runtime），能够在程序执行过程中动态地将虚拟量子比特映射到物理量子比特，并支持条件分支、循环、中间测量重置等高级控制流操作。**图 1** 展示了 Helios 陷阱中 98 个被共振激光照亮的离子，**图 2** 则概括了陷阱的功能区划分与典型的离子运输流程。

## 二、物理实现与技术细节

### 2.1 离子种类与能级结构

Helios 的量子比特由 $^{137}\mathrm{Ba}^+$ 离子的超精细基态能级定义：$|0\rangle = |F=1, m_F=0\rangle$，$|1\rangle = |F=2, m_F=0\rangle$。这两个能级构成钟态（clock state）对磁场波动具有二阶不敏感性，从而降低了环境磁场噪声的影响。为了在离子运输和门操作过程中维持极低的运动温度，系统中同时囚禁了 $^{171}\mathrm{Yb}^+$ 离子作为冷却剂，通过协同冷却（sympathetic cooling）为 Ba⁺ 离子提供有效的基态冷却。**图 3(d)** 给出了 $^{137}\mathrm{Ba}^+$ 的完整能级图，标明了用于状态制备、测量和量子门操作的主要光学跃迁。

### 2.2 陷阱架构与离子运输

Helios 的表面电极陷阱在二维平面上划分出功能各异的区域：**量子逻辑区**包含 8 个操作区（zone），每个操作区都配备独立的激光束和电极，能够执行单比特门、双比特门、状态准备、测量以及基态冷却；**存储区**则包括环形存储（ring）、腿部存储（leg）和缓存（cache），用于存放暂时不参与计算的量子比特。环形存储通过一个 X 型交叉结与量子逻辑区相连（**图 2c**），该交叉结允许离子在存储环和逻辑区之间按需路由，同时支持多个离子晶体的并行移动。**图 2(a)–(b)** 演示了从环形存储中选取特定离子并载入缓存区的过程。在典型的程序执行中，每个“层”（layer）包含最多 7 个批次（batch），每个批次可处理最多 16 个量子比特。量子操作在 8 个操作区中并行进行，而双比特门则只在那 8 个区中的 4 个区执行，并通过相邻区的移位操作实现对全部 8 个离子对的门操作。**图 4** 给出了随机程序对 98 个量子比特执行一层操作时的时间预算分解，其中离子运输和冷却占据了主要部分。

### 2.3 激光系统与量子门操作

Helios 的所有量子门操作均基于受激拉曼跃迁实现。单比特门使用一对共线传播的 515 nm 激光束，其频率差等于 8.04 GHz 的量子比特分裂。由于采用共线配置，门操作对离子热运动的敏感性被降至最低。单比特门的形式为 $U_{1Q}(\theta,\phi)=e^{-i\theta/2(\cos\phi X+\sin\phi Y)}$，而绕 Z 轴的旋转则通过软件中的相位更新来实现。双比特门基于 Mølmer–Sørensen 机制：两束激光以 90° 相交于操作区，其差动波矢沿离子晶体的轴向，激发晶体的拉伸模式。通过包裹脉冲（wrapper pulses）消除激光的随机光学相位，最终实现的原生门为 $R_{ZZ}(\theta)=e^{-iZZ\theta/2}$。**图 2(e)** 展示了双比特门激光束与离子晶体的空间关系。

状态制备和测量（SPAM）使用了多个波长的激光（493 nm、614 nm、650 nm 和 1762 nm）。标准测量先利用 1762 nm 激光将 $|0\rangle$ 态布居到 $D_{5/2}$ 能级（搁置，shelving），然后使用 493 nm 和 650 nm 激光激发 $S_{1/2}$ 能级上的离子产生荧光以区分 $|0\rangle$ 和 $|1\rangle$。当需要整批测量 16 个量子比特时，系统会自动切换到“保护测量”模式，同时搁置所有量子比特以避免测量光对相邻离子的串扰。此外，用户还可以选择“三元测量”（**图 3c**），该模式能够检测量子比特是否泄漏出计算子空间，而不需要额外的辅助量子比特。**图 3(a)–(c)** 分别描绘了标准测量、保护测量和三元测量的脉冲序列。

### 2.4 实时编译与动态程序支持

与大多数量子计算机使用预先静态编译的方式不同，Helios 配备了一个名为 Helios Runtime 的实时控制层。该运行时系统在程序执行过程中维护一份物理 QPU 状态模型，并实时完成虚拟量子比特到物理量子比特的映射。它将用户提交的声明式门操作（例如“对虚拟 qubit A 和 B 执行受控 Z 门”）自动分解为一系列并行的物理操作，并通过计算环形存储中的离子距离来决定如何以最少的旋转次数将所需离子对移动到缓存区和逻辑区。这一“排序”算法是 O(n) 复杂度的，确保了对于全连接量子程序的快速响应。更重要的是，Helios Runtime 支持动态电路：程序可以根据中间测量结果执行条件分支（if‑then‑else）、循环和提前终止。例如，在随机数产生或量子纠错的重复直到成功（repeat‑until‑success）协议中，系统能够实时决定是否需要重复某个操作序列。这种能力使得 Helios 不仅可以执行静态的量子线路，还能运行与经典控制流深度耦合的高级量子算法。

## 三、性能基准测试结果

### 3.1 组件级基准

组件级基准测试用于量化 Helios 中各个基本操作的错误率。所有结果汇总于表 I。这些数据是在全部 8 个量子逻辑区上平均得到的，且均包含了泄漏错误的影响（通过三元测量分离）。

**表 I：Helios 组件级平均错误率（infidelity）**

| 操作类型                | 平均错误率（×10⁻⁴）   |
| :------------------ | :------------- |
| 单比特门（Clifford 随机基准） | $0.25\pm 0.01$ |
| 双比特门（2Q 随机基准）       | $7.9\pm 0.2$   |
| 双比特门（循环基准）          | $8.1\pm 0.2$   |
| 状态制备与测量（标准）         | $4.8 \pm 0.6$  |
| 状态制备与测量（三元）         | $17\pm 1$      |
| 运输空闲错误（线性项）         | $5\pm 1$       |
| 运输空闲错误（二次项）         | $0.7\pm 0.2$   |
| 中间测量重置串扰（全局，每 MCMR） | $0.48\pm 0.01$ |

单比特门的平均错误率为 $2.5\times10^{-5}$，其中泄漏贡献约为 $1.1\times10^{-5}$。**图 5** 展示了 16 个位于逻辑区的量子比特的 1Q 随机基准衰减曲线和泄漏增长曲线，所有量子比特的误差在空间上分布均匀，且统计检验未发现显著的相关错误（即串扰）。双比特门（$R_{ZZ}(\pi/2)$）的平均错误率为 $7.9\times10^{-4}$（2Q 随机基准）和 $8.1\times10^{-4}$（循环基准），泄漏贡献约为 $2.4\times10^{-4}$。

运输空闲错误是指量子比特在离子运输和冷却过程中因磁场时空不均匀性而累积的误差。通过一种将随机运输插入到 1Q 随机基准中的方法（**图 9**），作者测量了错误率随运输轮数增长的关系（**图 8**）。线性记忆错误率为 $5\times10^{-4}$ 每深度‑1 运输操作，而二次项系数为 $7\times10^{-5}$，后者反映了较慢的磁场漂移。值得注意的是，运输空闲错误中的泄漏部分几乎贡献了整个线性项，表明运输过程中的光子散射或背景气体碰撞是主要的泄漏来源。

中间测量与重置（MCMR）会对相邻的旁观者量子比特造成串扰，主要是由于散射的测量光引起自发辐射。**图 10** 量化了当某个目标量子比特反复 MCMR 时，周围不同位置旁观者量子比特的错误通道。与目标位于同一操作区或紧邻上下区的离子（局部串扰）平均错误率为 $2.1\times10^{-4}$，而位于环形存储区的远距离旁观者（全局串扰）错误率仅为 $4.8\times10^{-5}$。这一数据表明 Helios 的陷阱设计和测量光隔离已经将全局串扰控制到较低水平。

### 3.2 系统级基准

组件级基准虽然重要，但真正的系统性能需要在整个芯片上同时执行多种操作时才能体现。为此，作者进行了两类系统级基准测试。

第一类是对随机 Clifford 电路进行二进制随机基准（BiRB）的扩展，其中每个电路层不仅包含随机的单比特 Clifford 门和随机配对的 $R_{ZZ}(\pi/2)$ 门，还包含了指定数量的中间测量与重置（MCMR）。**图 11** 给出了一个简化的示例电路。通过追踪一个随机初始稳定子经过整个电路后的符号变化，可以定义每次实验的成功或失败，并由此计算出每层的极化度和过程保真度。**图 12(a)** 显示了对于每层 0、8、16 次 MCMR 的不同设置，极化度随电路深度指数衰减的情况。从衰减率中提取的有效 2Q 门错误率为 $2.0(3)\times10^{-3}$，与将表 I 中的 2Q 门错误和运输空闲错误相加后的预测值（$2.2\times10^{-3}$）高度吻合。当 MCMR 次数从 8 增加到 16 时，层保真度反而略有上升（**图 12(b)**），这是因为 16 次 MCMR 对应了整批 16 个量子比特同时测量，此时系统会自动启用“保护测量”模式，避免了操作区内的串扰，从而补偿了额外测量带来的误差。

第二类系统级基准是随机电路采样（RCS）的镜像基准。RCS 被广泛用于展示量子计算机的超越经典能力，但其保真度通常需要通过计算与理想输出的交叉熵来估计，而对于 98 个量子比特的中等深度电路，精确模拟理想输出已经不可能。镜像基准通过构建“前半随机 + 后半反向编译”的电路，使得理想输出退化为输入态，从而可以直接通过测量返回输入态的概率来估计保真度，同时通过随机编译消除相干误差对保真度估计的污染。**图 13(a)** 展示了 Helios 对 98 个量子比特执行不同深度镜像电路所得到的保真度。拟合表明有效 2Q 错误率再次为 $2.0\times10^{-3}$，与 Clifford 电路结果一致。更为重要的是，作者使用张量网络收缩方法估算了经典超级计算机从相同深度和随机性的正向 RCS 电路中抽取一个样本所需的计算成本（**图 13(b)**）。结果显示，对于 Helios 能够以高保真度运行的电路深度，即使是拥有无限内存的最先进超算，其采样一个样本的时间也长达数十年到数百年，这意味着 Helios 产生的量子态已经远远超出了经典模拟的能力范围。
