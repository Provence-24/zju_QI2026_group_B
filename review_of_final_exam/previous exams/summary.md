
# 历年题考点分析

## 一、超高频考点（三年均出现，必须滚瓜烂熟）

### 1. 量子纠错码（3-bit Repetition Code）
- **22-23**：编码逻辑比特、错误症状提取、相位翻转错误的**局限性**（无法纠正 phase flip）。
- **23-24**：错误症状提取电路、 syndrome 测量、5条线概率 $p$ 下的可靠性计算。
- **24-25**：多比特同时翻转的 syndrome、单比特纠错操作、**复合错误**（phase + bit-flip）的分析与恢复。
- **核心**：必须掌握 syndrome table、辅助比特测量结果与对应恢复操作的映射，以及该码只能纠正单比特 bit-flip、不能纠正 phase-flip 的本质原因。

### 2. 超导量子比特与哈密顿量
- **22-23**：超导比特中门不完美性的物理起源（$T_1, T_2$、脉冲畸变、ZZ耦合、泄漏等）。
- **23-24**：谐振子近似 $H \approx 4E_C\hat{n}^2 + \frac{1}{2}E_J\hat{\varphi}^2$、等离子体频率 $\Omega_J$ 推导、耦合谐振子简正模式。
- **24-25**：有效哈密顿量 $H_{\mathrm{eff}} = -J\sigma_{1z}\sigma_{2x}$、时间演化算符 $U = e^{-iH_{\mathrm{eff}}t}$、利用演化算符构造 CNOT。
- **核心**：从电路量子电动力学（cQED）的谐振子图像到有效自旋哈密顿量的过渡是课程重点。

### 3. 密度矩阵、量子态表示与演化
- **22-23**：纯态与叠加态的密度矩阵、Kraus 表示下的系统+环境联合演化。
- **23-24**：布洛赫球参数化 $|\psi\rangle = \cos\frac{\theta}{2}|0\rangle + e^{i\phi}\sin\frac{\theta}{2}|1\rangle$、泡利矩阵期望值、Hadamard 门后的密度矩阵。
- **24-25**：Bloch 向量 $\vec{r}$ 的提取、纯态（$|\vec{r}|=1$）与经典混合态（$|\vec{r}|<1$）的判定。
- **核心**：密度矩阵是连接纯态语言与开放系统/噪声语言的桥梁，必须熟练进行矩阵运算与门演化。

### 4. 海森堡相互作用与含时演化
- **22-23**：两量子比特海森堡模型 $H = -J(\vec{\sigma}_1\cdot\vec{\sigma}_2)$ 的基态与纠缠判定。
- **23-24**：同一海森堡哈密顿量下的时间演化 $U = e^{-iH\Delta t/\hbar}$（$\Delta t = \pi\hbar/4J$）、演化后的密度矩阵。
- **24-25**：有效相互作用 $Z\otimes X$ 下的时间演化、演化时间的精确求解（分数幂思想 $U(t) = U(2t)^{1/2}$）。
- **核心**：双比特耦合模型的能谱与演化算符是课程计算题的基本盘。

### 5. 纠缠与纠缠熵
- **22-23**：海森堡模型基态的纠缠判定。
- **23-24**：Von Neumann 熵 $S = -\mathrm{Tr}(\rho_A\log_2\rho_A)$ 的计算、混合态（概率 $1-p$ 与 $p$）的熵、熵最大时的 $p$ 值。
- **24-25**：Bell 态 $|\Psi_+\rangle$ 的纠缠熵、参数化态 $|\Psi\rangle = \cos\frac{\theta}{2}|01\rangle + e^{i\phi}\sin\frac{\theta}{2}|10\rangle$ 的熵、证明 Bell 态为熵最大情况。
- **核心**：约化密度矩阵 $\rho_A = \mathrm{Tr}_B(\rho)$ 的计算是求熵的前提，必须熟练。


## 二、高频考点（两年出现，重点掌握）

### 6. Grover 搜索算法
- **22-23**：Grover 迭代的四个阶段（初态制备、Oracle、扩散变换、测量）、扩散算子 $W = 2|\psi\rangle\langle\psi| - I$ 的化简、Oracle 与扩散算符的电路识别。
- **23-24**：电路状态追踪（时刻 1、4、9）、Oracle 与扩散算子的电路结构、用有限门集（1 CNOT + 2 H + 2 Z + 2 X）等价替换扩散电路。
- **核心**：振幅放大几何解释、Oracle 的相位翻转功能、扩散算子的"关于平均值反演"本质。

### 7. 量子门分解与通用门集
- **22-23**：旋转算符 $R_Y(\theta)$ 的矩阵指数形式、Hadamard 门的欧拉角分解（$H = R_Z(\pi)R_Y(\pi/2)$ 等）。
- **24-25**：通用门集 $\{H, S, T, \mathrm{CNOT}\}$、$X$ 门分解为 H, S, T 组合、给定双比特门 $G$ 的矩阵分解。
- **核心**：单比特门的欧拉角分解、双比特门（如 SWAP、CNOT）的电路等价性是课程对"量子电路"部分的基本要求。

### 8. 偏迹（Partial Trace）与约化密度矩阵
- **23-24**：对第二个量子比特测量（忽略结果）后，求第一个量子比特的约化密度矩阵。
- **24-25**：纠缠熵定义中 $\rho_A = \mathrm{Tr}_B(\rho)$ 的隐含使用。
- **核心**：偏迹运算是从总系统提取子系统信息的唯一工具，与测量、纠缠分析深度绑定。


## 三、一年出现但极为重要（必会，常考且基础）

### 9. 量子傅里叶变换（QFT）
- **24-25**：单比特 QFT（Hadamard）、两比特 QFT 电路（$H$ + 受控 $S$）验证、三比特推广、与 FFT 的复杂度比较。
- **重要性**：QFT 是 Shor 算法的核心，属于量子计算"四大算法"（Shor、Grover、Simon、Deutsch-Jozsa）的数学基础。虽未在 22-23 直接出题，但课程地位极高，必须会推电路。

### 10. 不可克隆定理（No-Cloning Theorem）
- **22-23**：利用内积酉不变性证明 $\langle\psi|\phi\rangle = (\langle\psi|\phi\rangle)^2$ 导致矛盾；也可通过线性性证明。
- **重要性**：量子信息两大基石定理之一（与量子态不可区分/测不准原理并列），证明逻辑简洁且必考。

### 11. Kraus 算子与开放系统（退相位/退相干）
- **22-23**：系统+环境联合酉演化后对环境求偏迹推导 Kraus 算子 $E_0, E_1$；退相位通道 $E_0 = \sqrt{1-p}I, E_1 = \sqrt{p}Z$；$T_2$ 与密度矩阵非对角元指数衰减 $e^{-t/T_2}$。
- **重要性**：连接理想酉演化与真实噪声的桥梁，理解 $T_1$（能量弛豫）与 $T_2$（相位退相干）的物理意义是实验量子计算的入门。

### 12. Bell 态与量子通信协议
- **23-24**：超密编码（Superdense Coding）——Alice 对 Bell 态施加 $X, Z, ZX$ 后系统状态、Bob 的 Bell 基测量解码。
- **重要性**：Bell 态是纠缠的"标准参照物"，超密编码与量子隐形传态（Quantum Teleportation）并称量子通信两大协议。即使某一年不直接考大题，也常以子问题形式出现。

### 13. 量子谐振子模型（含驱动/耦合）
- **22-23**：含驱动力的量子谐振子时间演化。
- **23-24 / 24-25**：超导量子比特的谐振子近似与简正模式。
- **重要性**：谐振子是超导量子比特（transmon、fluxonium 等）的理论母体，理解 $\hat{n}$ 与 $\hat{\varphi}$ 的对易关系、能级量子化是后续学习量子光学/电路 QED 的前提。

# 22-23年
 
### 第1题（海森堡相互作用模型）

- **两量子比特基态的求解**
- **纠缠态的判定**

### 第2题（含控制项的量子谐振子与时间演化）


- **含驱动力的量子谐振子**
- **时间演化问题**
  
### 第3题（门不完美性与量子纠错码）

- **门不完美性（Gate Imperfection）的物理起源**：在**超导量子比特**中，具体来源包括**退相干**（能量弛豫 $T_1$、相位退相干 $T_2$）、**控制脉冲的畸变/过冲**、**泄漏**（leakage to non-computational states）、**ZZ寄生耦合**以及**量子比特频率的静态失谐**。

- **3比特重复码（3-bit repetition code）**：编码逻辑比特（$|0_L\rangle = |000\rangle, |1_L\rangle = |111\rangle$）; 纠错过程（**错误症状提取** using ancillary qubits, **综合征测量**, **恢复操作**）。

- **相位错误的纠错能力分析**：明确**3-bit repetition code 无法纠正相位翻转（Phase flip / Z error）**，因为相位错误 $Z$ 在此编码下等同于对三个物理比特的比特翻转错误组合（如 $Z_i Z_j$），导致症状测量失效；引入**相位翻转码**或**Shor码**的概念对比。


### 第4题（通用量子门与门合成）


- **旋转算符的定义**：$Y_{\pi/2}$ 的矩阵指数形式 $R_Y(\theta) = e^{-i\theta Y/2} = \cos(\theta/2)I - i\sin(\theta/2)Y$，代入 $\theta = \pi/2$ 写出具体矩阵。

- **通用门集**：单比特旋转门（$X_\theta, Y_\theta, Z_\theta$）、相位门（$Ph_\theta$）与两比特门（CNOT）的通用性。

- **Hadamard门的分解**：利用欧拉角公式或布洛赫球旋转，将 $H$ 门分解为绕 $Y$ 轴和 $Z$ 轴（或 $X$ 轴）的旋转组合，例如 $H = R_Z(\pi) R_Y(\pi/2)$ 或 $H = R_Y(\pi/2) R_Z(\pi)$ 等（需识别相位门的贡献）。

  
### 第5题（Kraus算子与退相位（Phase Damping））


- **密度矩阵**：纯态 $|0\rangle$ 和叠加态 $\frac{1}{\sqrt{2}}(|0\rangle+|1\rangle)$ 的矩阵表示及其非对角项（相干项）。

- **Kraus表示（算符和表示）**：对系统+环境（$\rho' \otimes \rho_E$）进行**酉演化后对环境求偏迹（partial trace）**，从而推导出作用于系统的主方程中的Kraus算子 $E_0, E_1$。

- **退相位通道（Phase Damping Channel）**：Kraus算子的标准形式（如 $E_0 = \sqrt{1-p}I, E_1 = \sqrt{p}Z$）；特征时间 $T_2$（相位相干时间）与退相位速率 $\gamma = 1/T_2$ 的关系；理解密度矩阵非对角元随时间指数衰减 $e^{-t/T_2}$。

  

### 第6题（Grover搜索算法）

- **Grover迭代的四个阶段**：**初态制备**（均匀叠加态）、**Oracle（黑盒）** 作用（标记目标态，翻转相位）、**扩散变换（Diffusion operator）**（幅度放大，即关于平均值的反演）、**测量**。

- **各阶段表达式化简**：写出门操作的矩阵形式，利用叠加态 $|\psi\rangle = \frac{1}{\sqrt{N}}\sum_x |x\rangle$ 的性质化简扩散算子 $W = 2|\psi\rangle\langle\psi| - I$，并给出一次迭代后的振幅变化通式。

- **初态制备**：对 $|0\rangle^{\otimes n}$ 施加 **Hadamard 门层（$H^{\otimes n}$）**；指出电路图中该阶段的位置。

- **扩散算符的识别**：指出电路图中对应 $W$ 的阶段（通常由 $H^{\otimes n}, X^{\otimes n}$、受控相位门 $C^{n-1}Z$ 和反变换构成）。

- **Oracle的功能**：Oracle 对应标记特定目标态（搜索解）；指出电路图中Oracle的位置及其作用（条件相位翻转，如 $U_\omega |x\rangle = (-1)^{f(x)} |x\rangle$）。

  
### 第7题（不可克隆定理的证明）


- **不可克隆定理（No-cloning Theorem）** 的证明逻辑：假设存在一个**酉变换（Unitary operator）** $U$ 能将任意未知态 $|\psi\rangle$ 与辅助态 $|0\rangle$ 克隆为 $|\psi\rangle|\psi\rangle$。

- **利用内积的酉不变性（幺正性）**：对两个不同的未知态 $|\psi\rangle$ 和 $|\phi\rangle$ 分别应用克隆过程，比较克隆前后的内积，得到矛盾方程 $\langle\psi|\phi\rangle = (\langle\psi|\phi\rangle)^2$，推导出该方程仅当内积为0或1时成立，与“任意态”的前提矛盾。

- **量子态线性性的体现**：也可通过线性算符作用在叠加态上的矛盾来证明（非克隆算符不可线性）。

# 23-24年

### 第I题（量子态计算）

- **布洛赫球表示**：量子态 $|\psi\rangle = \cos\frac{\theta}{2}|0\rangle + e^{i\phi}\sin\frac{\theta}{2}|1\rangle$ 的参数化形式。
- **泡利矩阵的线性组合 $\vec{n}\cdot\vec{\sigma}$**：其中 $\vec{n} = (\sin\theta\cos\phi, \sin\theta\sin\phi, \cos\theta)$，证明 $|\psi\rangle$ 为其本征态并求本征值。
- **期望值计算**：求 $\langle\psi|\sigma_x|\psi\rangle$ 与 $\langle\psi|\sigma_z|\psi\rangle$，并构造复线性组合。


### 第II题（含时演化计算）

- **密度矩阵的量子门演化**：对纯态密度矩阵 $\rho_1^{(0)} = \frac{1}{2}\begin{pmatrix}1&1\\1&1\end{pmatrix}$（即 $|+\rangle\langle+|$）施加 Hadamard 门，计算 $\rho_1 = H\rho_1^{(0)}H^\dagger$。
- **海森堡相互作用模型**：双量子比特哈密顿量 $H = -J(\sigma_{1x}\sigma_{2x} + \sigma_{1y}\sigma_{2y} + \sigma_{1z}\sigma_{2z})$ 的识别与演化算符 $U = e^{-iH\Delta t/\hbar}$ 的计算，其中 $\Delta t = \frac{\pi\hbar}{4J}$。
- **复合系统密度矩阵**：双量子比特初始态的张量积构造，以及含时演化后的总密度矩阵 $\rho_2$。
- **偏迹（Partial Trace）与约化密度矩阵**：对第二个量子比特进行测量并忽略结果后，对第一个量子比特求约化密度矩阵。


### 第III题（Von Neumann 纠缠熵）

- **混合态密度矩阵的构造**：系统以概率 $1-p$ 处于 $|0\rangle$、以概率 $p$ 处于 $\frac{1}{\sqrt{2}}(|0\rangle+|1\rangle)$，写出总密度矩阵 $\rho$。
- **Von Neumann 熵定义**：$S = -\mathrm{Tr}(\rho_A \log_2 \rho_A)$，通过求解 $\rho$ 的本征值计算熵。
- **熵的极值分析**：求 $S(p)$ 最大时对应的概率 $p$ 值。


### 第IV题（超密编码 Superdense Coding）

- **Bell 态（EPR 对）**：初始共享态 $\frac{1}{\sqrt{2}}(|00\rangle+|11\rangle)$ 的识别。
- **局域量子门对纠缠态的作用**：Alice 对自己的量子比特分别施加 $X$、$Z$、$ZX$ 门后，系统整体状态的变化（四种 Bell 态的生成）。
- **超密编码协议**：通过操作一个量子比特传递两个经典比特信息的原理。
- **Bell 基测量**：Alice 将量子比特发送给 Bob 后，Bob 需进行联合测量（Bell basis measurement）以解码信息。



### 第V题（Grover 搜索算法）

- **初态制备**：$q_1, q_0$ 均从 $|0\rangle$ 开始，经 Hadamard 门层制备均匀叠加态。
- **电路状态追踪**：计算时刻 1、4、9 处系统的量子态（涉及 Oracle 与扩散算子的作用）。
- **Oracle 与扩散算子的电路结构**：识别图中各阶段对应的功能（条件相位翻转、关于平均值的反演）。
- **门的等价替换**：判断能否用 1 个 CNOT、2 个 $H$、2 个 $Z$、2 个 $X$ 门替换 4–9 处的电路，并给出等价电路构造。



### 第VI题（量子纠错码）

- **3-bit 重复码**：编码逻辑比特 $|0_L\rangle = |000\rangle$、$|1_L\rangle = |111\rangle$。
- **错误症状提取（Syndrome Extraction）**：利用辅助比特进行稳定子测量，定位错误位置。
- **错误纠正能力分析**：解释该码可纠正单比特翻转（bit-flip）错误的原因（错误可检测且可逆）。
- **概率模型下的可靠性分析**：若 5 条线路各有概率 $p$ 发生错误，计算整个纠错电路能正确工作的概率。



### 第VII题（超导量子比特）

- **超导量子比特的谐振子近似**：哈密顿量 $H \approx 4E_C\hat{n}^2 + \frac{1}{2}E_J\hat{\varphi}^2$ 与标准量子谐振子形式的对应。
- **等离子体频率推导**：由 $\hat{n} = i\frac{d}{d\varphi}$ 出发，推导 $\Omega_J = \frac{1}{\hbar}\sqrt{8E_JE_C}$。
- **耦合谐振子系统**：双量子比特哈密顿量 $H = \sum_{i=1,2}\left(4E_C\hat{n}_i^2 + \frac{1}{2}E_J\varphi_i^2\right) + V\varphi_1\varphi_2$ 的能级求解。
- **简正模式（Normal Modes）**：将耦合的双谐振子系统对角化，用 $E_C, E_J, V$ 表示本征能量。

# 24-25年

### 第1题（Bloch Sphere）

- **密度矩阵的Bloch球表示**：$\rho = \frac{I + \vec{r}\cdot\vec{\sigma}}{2}$，其中 $\vec{r}$ 为三维实向量。
- **纯态与混合态的判定**：$|\vec{r}| = 1$ 时为纯态，$|\vec{r}| < 1$ 时为混合态。
- **经典概率混合态的Bloch向量**：以各 $1/2$ 概率处于 $|0\rangle$ 和 $|1\rangle$ 的混合态，求其对应的 $\vec{r}$。
- **纯态的Bloch向量**：对态 $|\Psi\rangle = \cos\frac{\theta}{2}|0\rangle + e^{i\phi}\sin\frac{\theta}{2}|1\rangle$，求其对应的 $\vec{r}$。


### 第2题（Circuit）

- **SWAP门的定义**：$|\psi\rangle|\phi\rangle \rightarrow |\phi\rangle|\psi\rangle$ 的量子门功能。
- **SWAP门的等价电路构造**：证明由 CNOT 门与 $X$ 门组合而成的给定电路等价于 SWAP 门。
- **量子电路的矩阵乘积验证**：通过逐门计算整体酉矩阵，验证其与 SWAP 门矩阵一致。


### 第3题（纠缠熵）

- **Von Neumann 纠缠熵定义**：$S_A = -\mathrm{Tr}(\rho_A \log_2 \rho_A)$，其中 $\rho_A = \mathrm{Tr}_B(\rho)$。
- **Bell 态的纠缠熵**：对 $|\Psi_+\rangle = \frac{1}{\sqrt{2}}(|01\rangle+|10\rangle)$ 计算其约化密度矩阵及熵。
- **参数化纠缠态的熵**：对 $|\Psi\rangle = \cos\frac{\theta}{2}|01\rangle + e^{i\phi}\sin\frac{\theta}{2}|10\rangle$ 计算纠缠熵。
- **纠缠熵的极值**：证明 Bell 态是纠缠熵取最大值的情况。



### 第4题（量子门）

- **通用量子门集**：{H, S, T, CNOT} 的通用性。
- **单比特门分解**：将 $X$ 门分解为 H, S, T 等基本门的组合。
- **双比特门分解**：对给定矩阵 $G = \frac{1}{\sqrt{2}}\begin{pmatrix}1&1&0&0\\1&-1&0&0\\0&0&1&-1\\0&0&-1&-1\end{pmatrix}$，将其分解为基本量子门（H, S, T, CNOT）的电路。
- **量子门的矩阵表示与电路实现**。



### 第5题（量子纠错）

- **3-bit 重复码**：编码 $|0_L\rangle = |000\rangle$、$|1_L\rangle = |111\rangle$，用于纠正比特翻转错误。
- **错误症状提取（Error Syndrome）**：通过辅助比特测量 $|x\rangle, |y\rangle$ 定位错误位置。
- **多比特翻转分析**：第一和第二数据比特同时发生比特翻转时，症状输出与数据比特终态。
- **单比特翻转纠错**：根据 $|x\rangle, |y\rangle$ 的测量结果，确定应施加的恢复操作。
- **复合错误分析**：第二比特相位翻转、第三比特比特翻转的联合错误，症状输出及纠错后结果；重复码对相位翻转的局限性及额外恢复操作。



### 第6题（量子傅里叶变换）

- **量子傅里叶变换（QFT）定义**：$y_k = \frac{1}{\sqrt{N}}\sum_{q=0}^{N-1} x_q e^{i\frac{2\pi k q}{N}}$。
- **单量子比特 QFT**：等价于 Hadamard 门。
- **两量子比特 QFT 电路**：由 $H$ 门与受控 $S$ 门（相位门）构成的线路验证。
- **基态验证**：对输入 $|00\rangle, |01\rangle, |10\rangle, |11\rangle$ 分别计算输出 $|k_1, k_2\rangle$，并与标准 QFT 对比；若不符，指出电路修改方式。
- **三量子比特 QFT 推广**：根据两比特分析，构造含 $H$ 门与受控 $T/S$ 门的三比特 QFT 线路。
- **复杂度比较**：量子傅里叶变换与经典快速傅里叶变换（FFT）在门数量上的复杂度差异。



### 第7题（超导量子比特的调控）

- **有效哈密顿量**：$H_{\mathrm{eff}} = -J \sigma_{1z}\sigma_{2x}$（即 $Z \otimes X$ 相互作用），计算其矩阵表示。
- **时间演化算符**：$U = e^{-iH_{\mathrm{eff}}t}$，求解使 $U$ 等效于 $(Z \otimes X)^{1/2}$ 的演化时间。
- **分数幂运算**：利用 $U(t) = (U(2t))^{1/2}$ 的提示进行推导。
- **CNOT 门的构造**：使用任意单比特量子门与第（2）问得到的 $(Z \otimes X)^{1/2}$ 算符，组合构造 CNOT 门。
